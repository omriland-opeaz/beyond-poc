# Slide template

Six slide types at 1280×720, built from the same tokens as the product. No deck
was supplied for this system, so these are derived from the intro screen and the
answer pattern rather than copied from an existing deck.

- `TitleSlide.html` — mark, two-line hero, one line of context.
- `SectionSlide.html` — full-bleed numbered opener. Lime for 01, water for 02, ink for 03.
- `StatementSlide.html` — the claim, the graph, and the method beside it.
- `BigNumberSlide.html` — one figure on ink, one sentence under it.
- `ComparisonSlide.html` — before and after across a single rule.
- `ClosingSlide.html` — the boundary, stated plainly.

Rules that carry over: no slide text under 24px, every figure tabular, at most
one full-bleed colour panel per two slides, and never two accents on a slide.
