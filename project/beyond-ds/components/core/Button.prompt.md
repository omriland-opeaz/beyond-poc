One-line: the action control — lime for the one thing the screen wants, outline for everything beside it.

```jsx
<Button size="lg">Ask your first question →</Button>
<Button variant="secondary">Keep the national view</Button>
<Button shape="square" size="md">Approve</Button>
<Button variant="danger" size="sm">Reconnect</Button>
```

Hover lifts a primary 1px and darkens to `--by-lime-hover`. Never lime type on a white button; use the outline variant.
