# Email templates

Two send-ready single-file templates, table-based, 600px, no external CSS.

- `alert.html` — a watch the user set has tripped. The threshold and the date
  they set it are always restated; the method sits under the fold.
- `weekly.html` — the cockpit as an email. Every item carries its "why".

Rules: Space Grotesk with a Helvetica/Arial fallback (webfonts do not load in
most clients — the fallback is the real typeface for many readers, so never rely
on tracking to carry a layout). Lime button with ink label, 100px radius. No
images beyond the mark. Numbers tabular where the client honours it.
