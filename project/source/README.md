# Source material

Everything the design system was built from. Nothing in here is part of the
system itself — treat it as the archive.

| File | What it is |
|---|---|
| `BEYOND-GUIDELINES.md` | The written brand spec: voice, palette, type scale, drawing rules, layout, screen patterns. The primary source. |
| `_beyond Platform v3 - Final.dc.html` | The current prototype. The component inventory and every exact value came from here. |
| `_beyond Platform v3.dc.html` | The working version of the same app. |
| `_beyond Platform v2.dc.html`, `_beyond Platform.dc.html` | Earlier iterations. |
| `_beyond Mark Options.dc.html` | Explorations of the mark. The lime-square-and-eclipse won. |
| `_beyond Look Directions.dc.html` | A rejected direction in blue + Inter. Kept as history; **not** part of the system. |
| `zoom.png` | Reference screenshot. |

These prototypes load `../support.js` and `../_ds/` from the project root, so
they keep working from this folder. If you lift `beyond-ds/` out into its own
project, leave this folder behind.
